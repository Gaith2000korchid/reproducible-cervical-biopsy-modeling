# Modélisation reproductible de biopsies cervicales

**Question / objectif :** Comparer des modèles prédictifs en limitant les fuites de données et en évaluant les choix de prétraitement.

**Candidatures concernées :** Data science santé, biostatistiques prédictives, recherche quantitative.

**Preuves consultables :** Code de validation imbriquée groupée, résultats hors pli, analyses de sensibilité, tests et workflow CI.

**Limites :** Validation interne sur un jeu transversal public ; pas de risque futur, de causalité ni de validation clinique externe.

Consulter le README pour les commandes, l’origine des ressources et les résultats. La présence de tests ou d’une CI ne valide pas à elle seule les conclusions scientifiques.
