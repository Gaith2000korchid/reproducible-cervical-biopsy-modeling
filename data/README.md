# Data

## Source

This project uses the **Cervical Cancer (Risk Factors)** dataset from the UCI Machine Learning Repository.

- UCI dataset identifier: 383
- DOI: https://doi.org/10.24432/C5Z310
- Source institution: Hospital Universitario de Caracas, Venezuela
- Observations: 858
- Variables: 36
- Official file: `risk_factors_cervical_cancer.csv`
- Dataset page: https://archive.ics.uci.edu/dataset/383/cervical+cancer+risk+factors

## Local organization

- `raw/`: unmodified data retrieved from the official source;
- `processed/`: reproducible intermediate datasets generated by project code.

The contents of these directories are ignored by Git. Placeholder `.gitkeep` files preserve the directory structure.

## Reproducibility

The dataset will be downloaded through project code. Users should not copy the Coursera version into this repository.

The download and validation workflow will verify:

- the expected number of observations and variables;
- the presence of the `Biopsy` outcome;
- the original column names;
- missing-value encoding;
- a file or content checksum when applicable.

## Data governance

This repository must not contain:

- private internship data;
- confidential clinical data;
- modified Coursera files;
- direct or indirect personal identifiers.

Only the publicly available UCI dataset is used.
